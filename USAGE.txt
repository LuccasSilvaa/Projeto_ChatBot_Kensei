Security Investigation Agent (VirusTotal + URLScan)

1) Install dependencies:
   pip install -r requirements.txt

2) Export API keys:
   export VIRUSTOTAL_API_KEY="{{VIRUSTOTAL_API_KEY}}"
   export URLSCAN_API_KEY="{{URLSCAN_API_KEY}}"

3) Run investigation:
   python3 security_investigator.py 8.8.8.8
   python3 security_investigator.py example.com
   python3 security_investigator.py https://example.com/login

4) JSON output:
   python3 security_investigator.py https://example.com --output json

Notes:
- VirusTotal key is required.
- URLScan key is optional but recommended to increase quotas and consistency.
